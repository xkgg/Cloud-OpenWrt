# 云编译 OpenWrt 固件
原作者 https://github.com/huangqian8/Cloud-OpenWrt


说明：
- 本项目使用 Github Actions 下载 [Lean](https://github.com/coolsnowwolf/lede) 的 `Openwrt` 源码仓库，进行云编译。
- 本项目编译固件适配 x86_64 软路由。
- 本项目不定期更新。
